Warehouse Management System adalah project sederhana berbasis Golang yang dikombinasikan dengan HTML, CSS, dan Bootstrap untuk menampilkan data warehouse seperti items, suppliers, orders, dan inventory dalam bentuk web dashboard.

Project ini dibuat sebagai portfolio untuk pembelajaran fullstack dasar (backend Go + frontend sederhana).

Back End & Fornt End 
-  Go (Golang)
- HTML
- CSS
- Bootstrap 5
- MySQL (basic usage)
- Standard net/http
